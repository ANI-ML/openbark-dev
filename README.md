# OpenBark

A local-first, open-source veterinary AI scribe. It records the consult and drafts the note, and the audio, transcript and records never leave your clinic. It runs on your own laptop, clinic server or phone, using open models you choose.

> **Status: pre-alpha (M0, spikes and skeleton).** Nothing here is ready for clinical use.
